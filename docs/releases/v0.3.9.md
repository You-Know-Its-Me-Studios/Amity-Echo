# Amity Echo v0.3.9

`/model` now uses a compact monochrome picker with model names on the left, readable descriptions on the right, a full-width highlighted row, and a clear `(current)` marker. The raw metadata panel has been removed.

Arrow keys, Page Up/Down, Home, End, Enter and Escape navigate the list. Long lists scroll with the selection; narrow terminals stack descriptions and clip text safely. Discovery, authenticated Cadenza connectivity, global selection and existing conversations are preserved.

The second-stage reasoning picker is conditional on executable effort choices from the inference adapter. Current Cadenza/1 does not expose reasoning-level controls, so its models select directly without a misleading effort screen.
