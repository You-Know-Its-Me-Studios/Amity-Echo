# Amity Echo v0.3.8

Echo connects to the configured Cadenza/1 WebSocket server without searching for an installation or starting a process. The default local development URL is `ws://127.0.0.1:7941/cadenza`; the URL is global and independent of the working directory. Echo reports `Cadenza unavailable` when the server is stopped and reports missing or rejected credentials separately.

Start Cadenza separately with its existing authenticated service configuration. Echo reads the matching credential from its configured environment or Windows Credential Manager reference. `/model` continues to show Cadenza's actual discovered models, and model selection persists globally. Remote Cadenza URLs remain supported through certificate-verified `wss://` using the same Cadenza/1 client.
