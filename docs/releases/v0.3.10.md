# Amity Echo v0.3.10

Model selection now confirms with `Model Switched to [Model Name]`. Startup displays `1 model available. Use /model to select.` (with plural wording for multiple models) when no model is selected, and omits connection chatter when the selected model is ready.

Ordinary connection and authentication messages use plain language. Engine names, protocol details and credential references remain in internal diagnostics rather than normal terminal errors. Connection settings use model-focused labels. Model discovery, selection, persistence, authentication and generation behavior are unchanged.
