# Amity Echo v0.3.11

All slash commands now use temporary display output. Command text, progress and completion messages disappear when the command closes, returning to the conversation without stale rows or panels.

Help, pickers and settings keep their existing interactions. Status, review results without a decision prompt, and command errors remain readable until Enter or Escape closes the temporary view. Actual conversation messages, assistant responses, session changes and persistent UI state are preserved.
